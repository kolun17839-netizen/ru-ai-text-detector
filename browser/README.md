# Черновик — нейродетектор художественной прозы

Бесплатный статический сайт на русском. Проверяет главы и отрывки от 80 слов до 40 000 знаков. Поддерживает вставку текста и TXT в UTF‑8, UTF‑16 с BOM или Windows‑1251. Рукопись обрабатывается в памяти вкладки. Для работы не нужны API, учётные записи, ключи или Python на сервере.

## Модель и ограничения

Используется трансформер v2 из исходного проекта, дообученный RuBERT Tiny2. Сборка переводит его в ONNX, сжимает таблицу эмбеддингов и проверяет расхождение с оригиналом на шести примерах проекта. В браузере применяется исходная изотоническая калибровка и порог v2. Глава делится на фрагменты примерно по 110 слов с учётом абзацев, границ предложений и лимита модели в 256 токенов. Короткие фрагменты (меньше 40 слов) показаны без численного балла. Оценка относится к фрагменту. Отдельной валидации на корпусе художественной прозы нет.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, в поле **Source** выберите **GitHub Actions**. Если GitHub предлагает включить Actions для форка, включите их на вкладке **Actions**. Запустите **Нейродетектор прозы · GitHub Pages → Run workflow** из ветки `main`. Последующие изменения в веб-версии автоматически запускают публикацию. Адрес сайта появится в настройках Pages и в результате задачи `deploy`.

Первый запуск анализа скачивает модель, токенизатор и WebAssembly с этого же сайта. Текст через сеть не передаётся.

## Сборка для другого статического хостинга

Из корня репозитория, с Python 3.11 и Node.js 22:

```sh
python -m pip install -r browser/requirements.txt
python browser/export_model.py
npm ci --prefix browser
npm run build --prefix browser
python -m http.server 8000 --directory browser/dist
```

Локальная проверка доступна на `http://localhost:8000/`. На хостинг загружается содержимое `browser/dist`.

## Рекламный блок

По умолчанию блок скрыт, рекламных запросов нет. Для подключения укажите в `browser/public/site-config.js` адрес отдельной HTTPS-страницы с рекламой и пересоберите сайт. Страница должна быть на другом origin и разрешать встраивание в iframe. Код внутри iframe изолирован от страницы с рукописью. Используйте рекламного провайдера, который поддерживает такой способ размещения, и проверьте условия хостинга. При дальнейшем переходе к коммерческому сервису готовую сборку можно перенести на другой статический хостинг.
